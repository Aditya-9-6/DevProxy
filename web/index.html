DevProxy Local Root CA

DevProxy dynamically intercepts and inspects HTTPS traffic via on-the-fly leaf certificate minting. To avoid browser SSL warnings, install the local DevProxy Root CA into your system or container trust store.

Download devproxy-ca.crt
Quick CLI Trust Commands:
# Linux / Debian / Ubuntu: sudo cp devproxy-ca.crt /usr/local/share/ca-certificates/ sudo update-ca-certificates # macOS: sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain devproxy-ca.crt # Windows (PowerShell Run as Admin): Import-Certificate -FilePath .\devproxy-ca.crt -CertStoreLocation Cert:\LocalMachine\Root # Node.js / Python / Curl environment variable: export NODE_EXTRA_CA_CERTS="$PWD/devproxy-ca.crt" export SSL_CERT_FILE="$PWD/devproxy-ca.crt" curl -x http://localhost:8080 --cacert devproxy-ca.crt https://httpbin.org/get
